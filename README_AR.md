# CYD AudioDeck — مشغّل MP3 للوحة CYD

مشغّل MP3 للوحة ESP32-2432S028 بشاشة 2.8 بوصة. يقرأ الأغاني من بطاقة microSD ويرسل الصوت إلى سماعات Bluetooth عبر A2DP.

## أهم نقطة: بطاقة الذاكرة ما راح تنفرمت

- البرنامج يفتح بطاقة microSD للقراءة فقط.
- لا يوجد في الكود أي أمر لتهيئة البطاقة أو إنشاء ملفات أو حذفها أو إعادة تسميتها أو الكتابة عليها.
- ملف النظام `firmware.bin` يخص ذاكرة الفلاش الداخلية للوحة CYD، وليس بطاقة microSD.
- إذا لم يستطع ESP32 قراءة نظام ملفات البطاقة، يعرض رسالة `SD not readable` ويتوقف. لا تغيّر تهيئة البطاقة ولا تحذف ملفاتك.
- دعم قارئ SD القياسي في Arduino-ESP32 موجّه عادةً إلى FAT16/FAT32؛ بطاقة exFAT قد لا تُقرأ. هذا لا يعني أن البرنامج سيحوّلها أو يفرمتها.

## الواجهة

- يبدأ الجهاز مباشرةً في شاشة `My Music`.
- يقرأ ملفات MP3 من المجلد الرئيسي والمجلدات الفرعية (حتى عمق 4) ويعرض أول 150 ملفًا.
- اضغط زر `BT` في أعلى الشاشة لفتح قائمة أجهزة Bluetooth القريبة.
- خلّ سماعتك في وضع الاقتران، ثم اضغط اسمها في القائمة.
- بعد نجاح الاتصال، ارجع للأغاني واضغط الأغنية المطلوبة.
- يتذكّر ESP32 آخر جهاز Bluetooth للاتصال التلقائي عند التشغيل التالي (حسب سلوك المكتبة والسماعة).
- زر `Zz` يطفئ إضاءة الشاشة فقط، بينما يستمر الصوت والبلوتوث. المس الشاشة لإضاءة الشاشة من جديد.

## وضع السكون واستهلاك الطاقة

وضع السكون هنا هو **إطفاء إضاءة الشاشة مع إبقاء تشغيل الأغنية والبلوتوث**. هذا يوفر استهلاك الإضاءة الخلفية، لكنه ليس إيقافًا كاملًا للمعالج أو البلوتوث. إيقاف المعالج كليًا سيقطع بث A2DP.

## المتطلبات

- لوحة ESP32-2432S028 / CYD بمتـحكم ESP32 الأصلي الذي يدعم Bluetooth Classic.
- بطاقة microSD فيها ملفات `.mp3`.
- سماعات Bluetooth تدعم A2DP Audio Sink.

ملاحظة: بعض اللوحات المباعة بالاسم نفسه تأتي بمتحكم شاشة مختلف. جهّزت ثلاث بيئات بناء: `cyd_ili9341_2` (الافتراضي)، `cyd_ili9341`، و`cyd_st7789`. النسخة التي لا تطابق متحكم شاشتك قد تعطي شاشة بيضاء أو ألوانًا غير صحيحة. مواصفات CYD وتوصيلاته موضحة في [مرجع أطراف اللوحة](https://github.com/khanhj/ESP32_2432S028/blob/main/PINS.md).

## ملفات المشروع

- `src/main.cpp` — البرنامج.
- `platformio.ini` — إعدادات البناء والمكتبات.
- `.github/workflows/build.yml` — بناء آلي لثلاث نسخ وإرفاق ملفات BIN.

## بناء ملفات BIN

### على جهاز فيه PlatformIO

1. ثبّت PlatformIO داخل Visual Studio Code.
2. افتح مجلد المشروع.
3. نفّذ بناء البيئة الافتراضية `cyd_ili9341_2`، أو اختر `cyd_ili9341` / `cyd_st7789` حسب نوع الشاشة.
4. ستجد الملفات في `.pio/build/<environment>/`، ومن ضمنها `firmware.bin` وملفات الإقلاع والتقسيم.

### البناء السحابي عبر GitHub Actions

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. افتح تبويب `Actions`.
3. شغّل `Build CYD AudioDeck firmware` أو ادفع تعديلًا جديدًا.
4. نزّل الـ Artifacts الخاص بالنسخة المطلوبة؛ يحتوي ملفات BIN التي أنتجها البناء.

## حالة البناء

هذا مجلد مصدر وإعداد بناء، وليس ملف BIN مترجمًا. لم يتوفر مترجم ESP32/PlatformIO داخل بيئة إنشاء هذه الحزمة، لذلك لم أضع ملفًا وهميًا باسم `.bin` ولم أصف البناء بأنه ناجح. ملفات BIN لا تُعتبر جاهزة إلا بعد نجاح عملية البناء الفعلية.

## حدود النسخة الحالية

- MP3 فقط، حتى 150 ملفًا.
- لا يوجد دعم لسماعات سلكية من مخرج اللوحة؛ P4 مخصص لمكبر الصوت الموجود على اللوحة، وليس منفذ سماعة 3.5 مم.
- قائمة الأجهزة تعرض حتى 10 أجهزة Bluetooth.
- يلزم اختبار اللمس واتصال سماعاتك على اللوحة نفسها بعد البناء؛ قد تحتاج معايرة اللمس حسب دفعة الشاشة.
