# CYD pin map used by AudioDeck

| Function | GPIO |
|---|---:|
| TFT MOSI / MISO / SCLK | 13 / 12 / 14 |
| TFT CS / DC / Backlight | 15 / 2 / 21 |
| SD MOSI / MISO / SCK / CS | 23 / 19 / 18 / 5 |
| Touch MOSI / MISO / CLK / CS / IRQ | 32 / 39 / 25 / 33 / 36 |

Audio is transmitted wirelessly using Bluetooth Classic A2DP. No speaker or wired audio accessory is needed.

The board's P4 speaker connector is connected to the onboard mono amplifier; it is not a 3.5 mm headphone jack.
